\# Capstone 3: EmporiUm Sales Analysis with Power BI

&#x20;

\## Project Overview

This project analyzes four years (2022–2025) of sales data for EmporiUm, a bookstore operating across multiple locations and online channels.

&#x20;

Using Power BI, the report explores sales performance, product categories, geographic trends, and top-selling titles within the Northeast region. The goal is to provide actionable insights that support data-driven business decisions for regional management.
